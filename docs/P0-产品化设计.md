# Skill 管理中心 · 产品化 P0 设计文档

版本：v1.0（2026-10-13）
状态：待评审
决策基线：Cloudflare 免费档 · D1 主库 · 邀请码注册 · 前期用户规模几十人 · 自有域名（购买中，上线前绑定）

---

## 1. 目标与边界

**目标**：把「个人 Skill 管理中心」升级为可多人使用的产品：
- 新用户注册（邀请码制）后，能浏览技能、看每日双档推荐、对技能表达感兴趣/不感兴趣/好用/没用
- 每个用户拥有**独立的技能状态**（待装/已装/待卸/不感兴趣），互不可见
- 反馈回流驱动个性化推荐（P1 起逐步生效）
- 用户本机通过 CLI 完成实际安装，状态自动回写

**边界（P0 不做）**：
- 不做开放注册、不做付费、不做社交
- 不迁移「快速入口」等纯前端配置（保留在页面内）
- 不做实时抓取，抓取仍走定时任务（GitHub Actions Cron），每日 09:00 前后执行

---

## 2. 总体架构

```
用户浏览器 (React SPA, 自有域名 + CDN)
        │  HTTPS
        ▼
Cloudflare Workers (REST API, 单 Worker 多路由)
   ├── /api/auth/*    账号与邀请码
   ├── /api/skills    技能/推荐/案例/手册
   ├── /api/feedback  兴趣与评价
   └── /api/command   安装指令（网页/CLI 共用）
        │
        ▼
Cloudflare D1 (SQLite 主库, 产品数据)   +   KV (JWT 会话, 限流)
        ▲
        │  GitHub Actions Cron (每日抓取 GitHub Trending + 聚合站 → 写 D1)
        │
飞书 Base —— 仅保留为内部运营后台（管理员看数），与 D1 单向同步（P0 迁移后停更）
```

## 3. 数据库 Schema（D1 / SQLite）

> 字段命名与现有 Base 对齐，迁移脚本按字段名直接转换。

```sql
-- 用户
CREATE TABLE users (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  email         TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  nickname      TEXT,
  tags          TEXT DEFAULT '[]',   -- 画像标签 JSON 数组，如 ["初中数学","口播","家长沟通"]
  role          TEXT DEFAULT 'user', -- user | admin
  created_at    TEXT DEFAULT (datetime('now','localtime'))
);

-- 邀请码
CREATE TABLE invite_codes (
  code       TEXT PRIMARY KEY,
  used_by    INTEGER REFERENCES users(id),
  used_at    TEXT,
  created_at TEXT DEFAULT (datetime('now','localtime'))
);

-- 技能台账（全站共享，迁移自 Base 台账表）
CREATE TABLE skills (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  name       TEXT UNIQUE NOT NULL,   -- 注册名/标识，如 security-audit
  cn         TEXT,                   -- 中文名
  cat        TEXT,                   -- 类别
  tags       TEXT DEFAULT '[]',      -- 功能标签 JSON
  biz        TEXT DEFAULT '[]',      -- 对应业务 JSON
  status     TEXT DEFAULT '未安装',  -- 全站默认态（迁移快照，用户态见 user_skill_states）
  backup     TEXT DEFAULT '未备份',
  hot        TEXT,                   -- 热度字符串
  source     TEXT,                   -- 来源 URL
  reg        TEXT,                   -- 可安装注册名（skills.sh owner/repo）
  score      INTEGER,                -- 效果评分 1-5
  desc       TEXT,                   -- 一句话说明
  note       TEXT,
  last_used  TEXT,
  created_at TEXT DEFAULT (datetime('now','localtime'))
);

-- 用户技能状态（每用户一行，产品核心表）
CREATE TABLE user_skill_states (
  user_id    INTEGER NOT NULL REFERENCES users(id),
  skill_id   INTEGER NOT NULL REFERENCES skills(id),
  status     TEXT NOT NULL DEFAULT '未安装', -- 未安装|已安装|待安装|待卸载|不感兴趣
  rating     TEXT,                    -- 好用|一般|没用
  note       TEXT,
  updated_at TEXT DEFAULT (datetime('now','localtime')),
  PRIMARY KEY (user_id, skill_id)
);

-- 每日推荐记录
CREATE TABLE recs (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  batch      TEXT NOT NULL,          -- "2026-10-13 推荐"
  date       TEXT NOT NULL,          -- "2026-10-13"
  type       TEXT NOT NULL,          -- 为你推荐 | 全网热门
  skill_id   INTEGER NOT NULL REFERENCES skills(id),
  hot        TEXT,
  source     TEXT,
  why        TEXT,                   -- 推荐理由
  created_at TEXT DEFAULT (datetime('now','localtime'))
);

-- 用法案例（全站共享）
CREATE TABLE cases (
  id       INTEGER PRIMARY KEY AUTOINCREMENT,
  name     TEXT,
  skill_id INTEGER REFERENCES skills(id),
  scene    TEXT,
  date     TEXT,
  effect   TEXT,
  link     TEXT,
  kind     TEXT,
  steps    TEXT,
  note     TEXT,
  cover    TEXT,
  bg       TEXT,
  time     TEXT,
  repro    TEXT
);

-- 技能手册（全站共享）
CREATE TABLE handbook (
  skill_id INTEGER PRIMARY KEY REFERENCES skills(id),
  goal     TEXT,
  prompt   TEXT,
  steps    TEXT,
  examples TEXT
);

-- 打磨记录（全站共享，管理员维护）
CREATE TABLE polish (
  id      INTEGER PRIMARY KEY AUTOINCREMENT,
  name    TEXT,
  scene   TEXT,
  status  TEXT,
  rounds  INTEGER,
  score   INTEGER,
  issues  TEXT,
  fixes   TEXT,
  tpl     TEXT,
  note    TEXT,
  date    TEXT
);

-- 安装指令（网页按钮与 CLI 共用；执行方 = 用户本机 CLI 或云电脑轮询）
CREATE TABLE commands (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id    INTEGER NOT NULL REFERENCES users(id),
  skill_id   INTEGER NOT NULL REFERENCES skills(id),
  act        TEXT NOT NULL,          -- 安装|卸载|恢复
  status     TEXT DEFAULT '待处理',  -- 待处理|处理中|已完成|失败
  executor   TEXT DEFAULT 'web',     -- web(网页提交) | cli(用户本机) | cloud(云电脑)
  result     TEXT,
  created_at TEXT DEFAULT (datetime('now','localtime')),
  handled_at TEXT
);
```

索引：
```sql
CREATE INDEX idx_states_user  ON user_skill_states(user_id, status);
CREATE INDEX idx_recs_batch   ON recs(batch);
CREATE INDEX idx_commands_uid ON commands(user_id, status);
CREATE INDEX idx_cases_skill  ON cases(skill_id);
```

## 4. API 设计（Workers，前缀 /api，JSON + JWT）

### 4.1 账号
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/auth/register | body: `{email, password, invite_code, nickname}`；校验邀请码（标记 used） |
| POST | /api/auth/login | body: `{email, password}` → `{token, user}` |
| GET  | /api/auth/me | 当前用户信息 + 画像标签 |
| POST | /api/auth/invite | **admin only**：生成邀请码，返回 `{code}` |

JWT：HS256，`env.JWT_SECRET` 注入；payload `{uid, role}`，有效期 30 天。

### 4.2 技能与推荐（登录即可）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET  | /api/skills | 全量技能列表；query `cat/tags/q/installed` 过滤 |
| GET  | /api/skills/:id | 详情 + 我的状态 + 案例 + 手册 |
| GET  | /api/recs/today | 今日双档（为你推荐 + 全网热门），附带每个技能我的状态 |
| GET  | /api/cases | 案例列表（支持按 skill 过滤） |

### 4.3 反馈与状态（登录即可）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/feedback | body: `{skill_id, act}`；act ∈ 感兴趣/不感兴趣/好用/没用/一般/请求试用 |
| PUT  | /api/states/:skillId | 直接设置我的技能状态（CLI 回写用）：`{status}` 或 `{rating}` |

反馈落库规则：
- 感兴趣 → `user_skill_states.status = 待安装`，写 feedback 记录
- 不感兴趣 → `user_skill_states.status = 不感兴趣`
- 好用/没用/一般 → `user_skill_states.rating`（同一技能最新一条覆盖；与现状逻辑一致）
- 写 feedback 表同时维护 states 表（原子）

### 4.4 安装指令（网页按钮 + CLI 共用）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/command | body: `{skill_id, act}`；创建/复用待处理指令（幂等，与现 Worker 逻辑一致） |
| POST | /api/command/:id/report | body: `{status: 完成/失败, result}`；**CLI 执行后回写** |
| GET  | /api/command/pending | 我的待处理指令（CLI 轮询拉取） |

### 4.5 管理（admin）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/admin/stats | 注册数、指令量、反馈量、今日推荐状态 |

## 5. 邀请码注册流程

1. 管理员（你）登录 → 「生成邀请码」（每次 1 个，可批量）
2. 把邀请码发给受邀用户
3. 新用户打开网站 → 注册页 → 填邮箱 + 密码 + 邀请码 + 昵称
4. 校验：`invite_codes` 表存在且 `used_by` 为空 → 建用户、码标记 used
5. 默认角色 user；第一个注册的管理员码手动在 D1 里设 `role=admin`

---

## 6. 数据迁移（Base → D1）

脚本：`migrate_base_to_d1.py`（复用现有 sync_from_base.py 的导出逻辑）

1. `lark-cli base +record-list` 全量导出 7 张表：台账 / 推荐 / 案例 / 反馈 / 指令 / 手册 / 打磨（当前 111+109+42+76+16+91+5 条）
2. 按字段名映射生成 SQL INSERT（tags/biz 字符串化 JSON，日期取前 10 位，关联技能按名称解析成 skill_id）
3. `wrangler d1 execute skill-center-db --file=seed.sql` 灌库
4. 校验：`SELECT COUNT(*)` 各表与 Base 记录数一致；抽查 5 条关键记录
5. 反馈/指令表按 `提交人 open_id → users.id` 映射到第一个 admin 用户（历史数据归 admin 名下）

迁移完成后 Base 停止写入（保留只读快照，作为运营后台展示）。

## 7. 前端改造计划（React SPA）

- 技术：Vite + React（无重型 UI 库，延续现有暖色系视觉，微调成组件化）
- 路由：
  - `/login` `/register`（邀请码注册）
  - `/` 首页（每日双档推荐 + 数据面板）
  - `/market` 技能市场（工具箱三态：待装/已装/待卸 + 筛选）
  - `/cases` 案例库
  - `/admin` 管理（仅 admin：邀请码生成、数据看板）
- 状态：登录态存 localStorage（JWT）；技能状态请求一次后本地缓存，按钮点击即时乐观更新 + 失败回滚
- 保持现有交互习惯：卡片感兴趣/不感兴趣、详情抽屉、···菜单（查看详情/卸载/不感兴趣）、已装行内「恢复」按钮
- 网页按钮 → POST /api/command 与 POST /api/feedback（不再依赖 workers.dev 域名，全部走自有域名）

## 8. CLI 安装器（P1 起点，P0 可先不做）

```bash
npx skill-center install <skill>   # 登录后执行
npx skill-center uninstall <skill>
npx skill-center login             # 邮箱+密码 → 存 token 到 ~/.skill-center
```

CLI 动作：
1. `npx skills add <reg>`（实际安装，复用 skills.sh）
2. POST /api/command/:id/report 回写「已完成」
3. 本机记录 installed 列表，`status` 查询用

P0 期间网页的「安装/卸载」按钮仍走云电脑轮询（现状），CLI 作为 P1 交付。
