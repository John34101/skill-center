# 第一章：专注力的真相

专注力不是一种天赋，更像一块肌肉：用对方法会变强，总被打断就会萎缩。

## 常见误区

- **误区一**：同时开很多标签页叫「高效」。多任务切换其实在交「切换税」。
- **误区二**：靠意志力硬扛。环境设计往往比意志力更可靠。
- **误区三**：越长的学习时段越好。对大多数人，25–50 分钟一段更可持续。

## 可立刻用的三个做法

1. **单任务窗口**：这一段时间只允许一件学习相关的事。
2. **外部承诺**：告诉自己「这一段结束前不看手机」，并把手机放到视线外。
3. **收尾复盘**：每段结束写下「我学到了什么 / 还有什么疑问」，方便之后划线与输出。

> 金句：注意力是学习的货币；你把它花在哪里，成长就出现在哪里。
