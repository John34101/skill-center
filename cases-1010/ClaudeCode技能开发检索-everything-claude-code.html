Claude Code 技能开发检索

2026-10-08 · 已验证可复现 · 检索 Claude Code 技能开发全链路要点

检索结论：开发一个 Claude Code 技能的最小闭环

  1. 定义 SKILL.md：frontmatter 写 name + description（description 决定何时被触发，要写「when … use」）；正文写步骤与规则。核心
  2. 目录规范：~/.claude/skills/<技能名>/SKILL.md（个人级）或 .claude/skills/（项目级）；可带 scripts/、references/ 子资源。
  3. 渐进披露：主文件保持简短，细节放 references/*.md，由主文件按需指引读取，节省上下文。
  4. 可执行资产：需要跑脚本时提供 scripts/ 并声明运行方式；规则类技能优先纯 Markdown。
  5. 验证方式：在 Claude Code 里用触发场景实测，观察 description 是否命中、流程是否闭环。

适用于「你」的直接用法

技能包 > 零散技能：参考 mattpocock/skills、hezkvectory/hermes-edu-skills 的「系列包」结构，把你的数学教学技能（教案/错题分析/家长回复）打包成一个 math-edu 系列，统一版本、统一分发。
触发词设计：description 里写清「当用户粘贴家长问题 / 上传错题 / 要求写教案时使用」，让 Claude Code 自动路由。
复盘：everything-claude-code 把「技能开发」从零散经验整理成可执行清单，写新技能前先过一遍这 5 步。
