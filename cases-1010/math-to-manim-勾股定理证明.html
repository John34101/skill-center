① 叙事弧（story before symbols）

Aha：两个正方形的面积差 = 4 个直角三角形面积 → c² = a² + b²

② Manim 场景代码方案

class Pythagoras(Scene):
    def construct(self):
        # 1. 几何先呈现：直角三角形 + 三边正方形
        tri = Triangle()  # 直角三角
        self.play(Create(tri))
        # 2. 面积对比：大正方形 - 4 个三角 = 中间小正方形
        #    c² = a² + b² 从"看得见"的面积关系里长出来
        # 3. 代数后置：公式逐项出现
        eq = MathTex("c^2", "=", "a^2", "+", "b^2")
        self.play(Write(eq))
